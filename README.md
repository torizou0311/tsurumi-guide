# 鶴見のハウスガイド（YOKOHAMA Still Retreat）

ゲストにスマホで見てもらうための、Web版ハウスマニュアルです。
プログラムの知識がなくても、下記の手順でメモ帳などを使って文章を直せます。

## まず知っておくこと

- このフォルダの `index.html` をダブルクリックすれば、そのままブラウザで確認できます。
- インターネットに公開するとき（GitHub Pagesなど）は、このフォルダをそのままアップロードするだけで動きます。特別な準備（ビルド）は不要です。
- ゲストには `index.html?room=103` のように、部屋番号つきのURLを送ってください。
  - 103号室の人には `.../index.html?room=103`
  - 202号室の人には `.../index.html?room=202`
  - 201号室の人には `.../index.html?room=201`
  - URLに部屋番号を付けないと「部屋を選んでください」という画面が出ます。

## 1. 文章を直したい（誤字修正・言い回しの変更など）

文章はすべて `js/i18n.js` というファイルの中にあります。

1. `js/i18n.js` をメモ帳（またはVSCodeなどのテキストエディタ）で開く
2. `en:`（英語）`ja:`（日本語）`'zh-Hant':`（繁体字中国語）`ko:`（韓国語）という4つの大きなかたまりがあります
3. 直したい言語の中から、直したい文章を探して書き換える
   - 例えば「チェックイン・チェックアウト」の文章を直したいときは、`checkin:` という部分を探します
4. 保存すれば、それだけで反映されます（他のファイルは触らなくてOKです）

### 文章の中の { } について

`{room}` `{floor}` `{keyboxSide}` のように { } で囲まれた部分は、
表示するときに自動で部屋ごとの内容（部屋番号・階数・キーボックスの位置）に
置き換わる「合言葉」です。消したり書き換えたりしないでください。

### 建物共通の文章について（重要）

103号室と202号室で内容が同じ文章（ハウスルール・ゴミ出し・避難場所など）は、
`js/i18n.js` の中に **1回だけ** 書いてあります。片方の部屋のためにここを直すと、
もう片方の部屋にも同じように反映されます。
「103だけ違う内容にしたい」という場合は、下の「2. 部屋ごとに内容を変えたい」を見てください。

## 2. 部屋ごとに内容を変えたい（Wi-Fi・キーボックスの位置など）

部屋ごとに違う情報は `data/rooms.js` にまとまっています。

- `wifi` の中の `ssid5`（5GHz）・`ssid24`（2.4GHz）・`pass`（パスワード）
- `keyboxSide`（キーボックスがドアの `left`＝左 か `right`＝右 か）
- `floor`（何階か）

数字や文字を書き換えて保存するだけで反映されます。

### 201号室について（現在「準備中」表示になっている理由）

201号室は、Wi-Fi情報とキーボックスの位置がまだ分かっていないため、
`data/rooms.js` の中で `null`（空っぽ）のままにしてあります。
情報が分かったら、103号室・202号室の書き方を真似して数字を入れてください。
入れると、自動で「準備中」の表示から実際の情報の表示に切り替わります。

## 3. 新しい部屋を追加したい

`data/rooms.js` を開いて、一番下に部屋の情報をコピー＆ペーストで1件追加するだけです。
文章（ハウスルールなど）は共通なので、新しく書く必要はありません。

## 4. 写真を差し替えたい・追加したい

写真は `images` フォルダの中にあります。

- `images/common/` … 建物・タクシー乗り場・地図など、どの部屋でも共通の写真
- `images/103/` … 103号室だけで使う写真（キーボックス、Wi-FiのQRコードなど）
- `images/202/` … 202号室だけで使う写真
- `images/201/` … 201号室用（現在は写真が入っていません）
- `images/listing/` … Airbnb掲載用の元写真（部屋番号ごとのフォルダ）。トップ画面に大きく出す部屋写真（ヒーロー画像）は、この中から選んで `data/rooms.js` の各部屋の `hero` にパスを指定しています。差し替えたいときはここから別の写真のパスに書き換えてください。

差し替えたいときは、**同じファイル名のまま**新しい写真で上書き保存してください。
ファイル名を変えた場合は、`data/rooms.js`（部屋別の写真）または
`data/content.js`（共通の写真）の中にある該当のファイルパスも書き換える必要があります。

201号室の写真を追加したいときは、`images/201/` の中に写真ファイルを置いたあと、
`data/rooms.js` の201号室の `photos: {}` の中に、103・202号室の書き方を真似して
`keybox: 'images/201/keybox.jpg'` のように1行追加してください。

## 5. セクション（メニュー項目）を増やしたい・並び替えたい

セクションの構成は `data/content.js` にあります。配列の順番がそのままメニューの表示順になります。
新しいセクションを作るときは、既存の項目をコピーして `id` を変え、
`js/i18n.js` の各言語にも同じ `id` の文章を追加してください。

## このサイトについて

- 4か国語対応（英語・日本語・繁体字中国語・韓国語）。ヘッダーでいつでも切り替えられます。
- スマホの画面幅360pxくらいから快適に使える設計です。
- 検索エンジンには載らないようにしてあります（`robots.txt` と `noindex` 設定）。
- ビルドや特別なソフトは不要です。HTML・CSS・JavaScriptだけで動きます。
